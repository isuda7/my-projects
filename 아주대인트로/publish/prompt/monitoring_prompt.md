# 아주대학교 인트로 프로젝트 감시 프롬프트

작업을 진행할 때마다 다음 규칙들이 잘 지켜지고 있는지 지속적으로 확인한다.

## 1. 파일 구조 무결성
- [ ] CSS, JS, HTML 코드가 `/html/index.html` 단일 파일 내에 모두 작성되고 있는가? 외부 파일로 분리되지 않았는가?

## 2. 주석 체계 검증 (가장 중요)
- [ ] Style(CSS) 영역에 `/* ==================== [그룹명] ==================== */`, `/* ---------------- [영역명] ---------------- */` 형태의 2단계 주석이 적용되었는가?
- [ ] Script(JS) 영역에 2단계 주석 체계가 올바르게 적용되었는가?
- [ ] Markup(HTML) 영역에 `<!-- ==================== [그룹명] ==================== -->`, `<!-- ---------------- [영역명] ---------------- -->` 형태의 2단계 주석이 적용되었는가?

## 3. 웹 폰트 무결성
- [ ] Pretendard 및 아주대 폰트 CDN(`default.css`)이 최상단에서 정상적으로 `import` 또는 `link` 되고 있는가?
- [ ] CSS에서 폰트 패밀리가 정상적으로 참조되고 있는가?

## 4. 크기 단위 및 레이아웃
- [ ] 픽셀(`px`) 대신 `rem` 단위가 적극적으로 사용되고 있는가?
- [ ] 최상위 `html` 태그의 폰트 사이즈 기준이 `1px`로 유지되고 있으며, `10px = 10rem` 공식이 맞게 쓰이고 있는가?
- [ ] 모바일/태블릿 등 작은 해상도에서 레이아웃이 깨지지 않는지 미디어 쿼리가 적용되어 있는가?

## 5. CSS 초기화 (Reset) 검증
- [ ] 폰트(`font-family`), 줄간격(`line-height`), 색상(`color`) 속성이 부모로부터 상속(`inherit`)되도록 기본값이 설정되어 있는가?
- [ ] iOS 및 모바일 디바이스 관련 meta 태그(`format-detection` 등) 및 css 초기화 속성이 누락 없이 반영되어 있는가?

## 6. 이미지 및 에셋 최적화
- [ ] 삽입되는 모든 png 이미지 파일이 모바일 해상도를 고려해 원본 사이즈의 3배수(3x) 파일로 적용되고 있는가?
- [ ] 삽입되는 svg 파일이 `currentColor`로 처리되어 있으며, 부모의 CSS `color` 속성에 의해 색상이 제어되도록 구성되었는가?
