# 아주대학교 인트로 프로젝트 기본 프롬프트

## 목표
아주대학교 인트로 페이지 단일 파일(`/html/index.html`)을 완벽한 반응형 웹으로 퍼블리싱한다.

## 1. 파일 구성 및 관리
- `/html/index.html` 단일 파일 내에 스타일(CSS), 스크립트(JS), 마크업(HTML)을 모두 포함한다. 외부 CSS/JS 파일을 분리하지 않는다 (폰트 CDN 제외).

## 2. 주석 체계 규칙
가독성을 높이기 위해 Style, Script, Markup 코드 전체에 **2단계 분류 체계(대분류 > 소분류)**의 주석을 의무적으로 적용한다.

*   **1단계: 대분류 / 그룹핑 (Grouping)**
    *   `<!-- ==================== [그룹명] ==================== -->` (HTML)
    *   `/* ==================== [그룹명] ==================== */` (CSS/JS)
*   **2단계: 소분류 / 영역구분 (Sectioning)**
    *   `<!-- ---------------- [영역명] ---------------- -->` (HTML)
    *   `/* ---------------- [영역명] ---------------- */` (CSS/JS)

## 3. 웹 폰트 적용
- 메인 폰트로 **Pretendard**, 포인트 폰트로 **아주대 폰트**를 사용한다.
- 아주대 CDN을 활용하여 불러온다.
  `<link rel="stylesheet" href="https://wzine.kr/ajou_presentation/_css/default.css">`

## 4. 디스플레이 및 반응형
- 기본 레이아웃은 **PC 해상도 1920px**을 기준으로 디자인에 최적화한다.
- 미디어 쿼리를 활용해 태블릿, 모바일 해상도까지 유연하게 대응하는 반응형 웹을 적용한다.
- 해상도 축소 시 폰트 사이즈와 컴포넌트 레이아웃(그리드, 스택 등)이 적절하게 변경되도록 대응한다.

## 5. 단위 및 크기 (REM)
- 크기 지정에는 `rem` 단위를 적극 사용한다.
- 직관적인 계산을 위해 `html` 태그의 기본 `font-size`를 `1px`로 지정하여, **`10px = 10rem`** 공식이 성립하도록 작업한다.

## 6. CSS 초기화 (Reset) 및 iOS 대응
- **기본 상속**: `font-family`, `line-height`, `color` 속성은 부모 요소의 값을 상속(`inherit`)받도록 설정한다.
- **모바일/iOS 최적화**:
  - 화면 확대 방지 (viewport meta 및 CSS `touch-action: pan-y;` 등 고려)
  - 전화번호, 이메일, 주소 등의 자동 링크 변환 방지 (`<meta name="format-detection" content="telephone=no, address=no, email=no">`)
  - 모바일 웹킷 브라우저의 탭 하이라이트 컬러 제거 (`-webkit-tap-highlight-color: transparent;`)
  - 기본 브라우저 외형 스타일 제거 (`-webkit-appearance: none;`)

## 7. 이미지 최적화 및 에셋 관리
- **PNG 해상도**: 모바일 디스플레이 및 레티나 화면을 고려하여, 모든 png 이미지 파일은 원본 사이즈의 **3배수(3x) 해상도** 파일로 제작하고 적용함을 원칙으로 한다.
- **SVG 색상 제어**: 미리 생성해둔 svg 파일들은 내부 `fill`이나 `stroke` 속성을 `currentColor`로 처리하여, CSS의 `color` 속성으로 색상을 유연하게 제어할 수 있도록 작업한다.
